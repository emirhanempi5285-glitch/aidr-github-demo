# CrowdStrike Enterprise HR Platform

## Overview

The CrowdStrike Enterprise HR Platform is a demonstration enterprise application used to validate GitHub MCP Server integration with CrowdStrike Falcon AI Detection and Response (AIDR).

The application simulates an enterprise Human Resources platform consisting of multiple services including authentication, employee management, payroll, leave management, reporting, and administrative functions.

## Features

- Employee Management
- Payroll Management
- Leave Management
- Authentication & RBAC
- REST APIs
- Docker Support
- Kubernetes Deployment
- Terraform Infrastructure
- GitHub Actions CI/CD

## Technology Stack

- Node.js
- Express.js
- MongoDB
- Docker
- Kubernetes
- Terraform

## Disclaimer

This repository is for demonstration purposes only.

All credentials, API keys, certificates, employee data and secrets are fictitious and are included solely for demonstrating CrowdStrike Falcon AIDR capabilities.

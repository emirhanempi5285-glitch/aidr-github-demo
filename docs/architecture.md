# Enterprise HR Platform Architecture

## Overview

The Enterprise HR Platform is a fictional application created for demonstrating GitHub MCP with CrowdStrike AIDR.

## Components

- Employee Service
- Payroll Service
- Authentication Service
- HR Database (HR-DEMO-DB)
- Finance Database (FINANCE-DEMO-DB)
- Employee Portal (EMPLOYEE-PORTAL-DEMO)

## Infrastructure

- Node.js
- Express
- MongoDB
- Docker
- GitHub Actions

## Data Classification

The platform processes:

- Employee Records
- Payroll Information
- Internal Contacts
- Financial Documents

All data contained within this repository is fictional.
